# FileHide 路径识别、自动锁定、批量操作与拖拽支持

## 目标

- 通过 Windows 文件身份识别同目录重命名，避免历史记录因路径变化失联。
- 增加可配置的会话自动锁定，降低软件长时间无人值守风险。
- 提供批量锁定结果汇总，单个失败不影响其他项目。
- 支持从资源管理器拖入文件和文件夹，复用批量锁定逻辑。

## 实施顺序

1. 为 `hidden_item` 增加可迁移的文件身份字段，并在列表刷新时做路径重同步。
2. 扩展会话状态和设置命令，实现超时检查、主动锁定与前端配置。
3. 增加批量锁定命令/API/UI，并限制单次数量，返回逐项成功/失败结果。
4. 接入 Tauri 拖放事件，加入拖拽提示层，统一调用批量入口。
5. 更新状态文案、README 和测试，执行格式检查、Rust/前端测试、生产构建。

## 验收标准

- 同目录重命名后刷新历史，记录自动更新到新路径；替换目标显示“路径已变化”。
- 自动锁定到期后敏感命令被拒绝，重新输入密码恢复访问；关闭选项可保持原行为。
- 多选或批量拖入时逐项处理并展示成功/失败数量。
- 不支持 WebView2 的行为保持现有提示；`cargo test`、Vitest、前端构建和 Tauri release 构建通过。
