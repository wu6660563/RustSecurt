# FileHide 快速锁定：管理员绕过与后续安全方案

**适用版本：** FileHide V1.1  
**最后更新：** 2026-09-07  
**定位：** 风险说明与后续版本设计依据，不是用户操作手册。

---

## 1. 当前功能的真实安全边界

FileHide V1.1 是“快速锁定/隐藏”工具，而不是加密工具。

锁定时，程序只为用户选择的文件或文件夹本身增加 Windows `Hidden` 与 `System` 属性；不会读取、移动、压缩、递归处理或加密内部文件。原始属性和历史记录保存在本地 SQLite 数据库中，以支持精确恢复。

因此，它能有效减少日常浏览、资源管理器默认视图、家庭成员或同事随手查看时的可见性；但它**不能阻止拥有电脑管理权限、能够修改资源管理器设置，或能够直接访问磁盘的人**。

产品文案必须持续使用“快速锁定”“隐藏”“防止日常浏览”，不得使用“加密”“绝对保护”“无法访问”等描述。

## 2. 管理员或熟悉 Windows 的用户可如何发现项目

| 途径 | 为什么能发现 | 对 V1.1 的影响 |
|---|---|---|
| 资源管理器显示隐藏项目 | `Hidden` 属性仅影响默认显示行为 | 文件夹会重新出现在资源管理器中 |
| 取消“隐藏受保护的操作系统文件” | `System` 属性同样只是显示层策略 | 同时显示带 `Hidden + System` 的项目 |
| 在地址栏输入已知完整路径 | 隐藏不会改变文件位置、名称或内容 | 若知道路径，仍可直接打开 |
| 命令行或脚本读取/修改文件属性 | Windows 属性可被系统工具查询和改写 | 可识别项目并移除隐藏属性 |
| 搜索磁盘或查看最近使用记录 | 文件内容和原路径仍留在原磁盘位置 | 可从名称、内容或历史痕迹定位项目 |
| 读取 FileHide 本地数据库 | 数据库保存明文路径、类型、原始属性和时间 | 可获得所有曾由 FileHide 管理过的路径清单 |
| 使用管理员权限、离线磁盘或另一系统访问 | 管理员可取得所有权，离线访问不受当前用户界面限制 | 任何基于属性或 ACL 的隐藏都可被绕过 |

当前数据库由 Tauri 的应用数据目录创建；通常位于用户 Roaming 配置目录下的 `com.filehide.desktop/filehide.db`。该数据库本身不是秘密存储区。

## 3. 风险结论

### 可接受场景

- 不希望文件在资源管理器默认视图中被随手看到。
- 需要对大文件夹进行毫秒级锁定，且不愿意等待复制或加密。
- 使用者接受“懂 Windows 设置的人可以绕过”。

### 不应使用当前功能的场景

- 防止本机管理员、设备所有者或具有物理磁盘访问能力的人读取文件。
- 存放证件扫描件、密钥、财务资料、医疗资料等必须保密的数据。
- 需要通过密码保证即使复制磁盘也无法读取数据的情况。

## 4. 后续处理路线

### V1.x：继续保持快速锁定定位

目标是提高可恢复性和认知准确性，而不是声称更强的安全性。

- 保留并完善 `已锁定 / 已恢复 / 路径失效 / 已外部解除` 状态检测。
- 在锁定前、项目列表和关于页面持续说明“快速锁定不是加密”。
- 提供历史记录导出、数据库备份和失效路径清理。
- 对外部取消隐藏、文件被移动或删除给出可操作提示。

### V2：可选的普通账户访问限制

可增加 ACL 模式：移除其他普通 Windows 账户的读取权限，并保留所有者的恢复权限。

这能防止其他非管理员账户直接打开文件夹，但不能防止当前账户、管理员、取得所有权的人或离线磁盘访问。ACL 模式必须保存并恢复完整原始安全描述符，并提供风险提示和故障恢复入口。

### V3：真正的加密保险箱

若产品目标升级为“即使管理员或磁盘被复制也无法读取内容”，应采用独立的加密保险箱设计：

- 使用经验证的 AEAD 算法，例如 AES-256-GCM 或 XChaCha20-Poly1305。
- 用 Argon2id 从用户密码派生密钥；只保存 salt、参数与验证信息，绝不保存明文密码或可直接使用的主密钥。
- 对文件内容和文件名元数据一并加密。
- 通过完整性校验、原子写入、崩溃恢复和备份机制防止数据损坏。
- 明确区分“首次导入/加密”与“锁定/解锁”：大文件夹首次加密受磁盘吞吐限制，不能承诺两秒完成；已在保险箱中的内容可实现秒级锁定。

## 5. 产品验收文案

以下表述可用于界面：

> 快速锁定会隐藏所选项目，适合防止日常浏览；它不是加密，熟悉 Windows 设置或拥有管理员权限的用户仍可能找到项目。

以下表述禁止使用：

- “文件已加密”
- “管理员无法访问”
- “绝对安全”
- “任何人都无法查看”

---

## 6. 决策记录

当前产品选择：**优先秒级隐藏体验，接受管理员与技术用户可绕过，不引入加密、系统服务或 ACL 复杂度。**

这与 FileHide V1.1 的设计原则一致：不移动文件、不修改内容、不递归扫描，仅修改 Windows 文件属性并提供可恢复的本地历史记录。
